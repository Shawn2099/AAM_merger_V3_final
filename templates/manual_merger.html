Manual PDF Merger

Isolated from AI pipeline (FR-14.11–14.13): Files you upload here are not stored in the database, not grouped into any PO Set, and have no po_no association. Output file name and destination are chosen by you at merge time (FR-14.12). This page is visually and navigationally separate from the automated dashboard.

Drag & drop PDFs here or click to select

    You may choose any name; by default the merged file is downloaded with this name — not auto-written to the pipeline output folder.
    Add at least 1 PDF to enable merge.

    How this differs from the automated pipeline

    • Pipeline dashboard: watches input_folder, groups by PO number, reconciles, auto-merges SI→DN→PO→(AWB→Customs) — all DB-backed.
    • This tool: you upload arbitrary PDFs, drag to reorder, click Merge — result is a direct download, no DB row, no audit log.
    • Quarantine cases: copy files from the quarantine folder into this tool to resolve manually (FR-13.8).
